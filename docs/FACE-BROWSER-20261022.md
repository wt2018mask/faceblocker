## 실제 시험에서 발견한 전체 가림과 수정

실행 당시 Face 시작 19:59:05.540 → Protecting 19:59:31.552 사이 약26초 전체 보호였다. 수정 전 로그의 얼굴 후보 좌표를 비대화형으로 재생하면 2,109회 중273회 CoverageGuard 부족을 재현했다. 약0.35 신뢰도의 후보는 추적되지만 0.6 임계값 마스크를 받지 못했고, 이미 유지 시간이 끝난 얼굴도 내부 트랙에 남아 전체 보호를 요구했다.

새 **Face 국소 불확실성 보호**는 낮은 신뢰도 후보에 추가50% 확장한 불투명 검은 사각형을 만든다. Outline/10% opacity/둥근 모서리를 선택해도 이 보호 사각형은 모든 픽셀이 불투명하다. 설정된 얼굴 유지 시간이 끝나고 분석이 계속 정상일 때는 만료된 얼굴을 전역 보호의 필수 대상으로 남기지 않는다. 얼굴 누락이 유지 시간보다 길면 검출 실패로 노출될 수 있으며, 이 정책은 검출 정확도를 보장하지 않는다.

UI에 이 정책과 tradeoff를 명시했고 `Expanded local guards for uncertain faces`를 끄면 엄격한 전체 불확실성 보호를 선택할 수 있다. **기존 해부학적 규칙, FailClosed 설정, 캡처/추론 실패·오래된 증거에 대한 전체 보호를 해제하지 않았다.** 수정 후 같은2,109개 좌표의 재생에서 커버리지 부족0회(수정 전273회)를 확인했다. 실제 모델의 정상 빈 장면 분석을3.2초 이어간 후 전역 보호 없이 국소 가림이 만료되며, 증거를1.6초 오래되게 하면 전체 보호가 여전히 작동하는 회귀 PASS. 수정 후의 브라우저 실제 표시 재검증은 NOT RUN이다. 좌표 재생은 분석 주기 근사이며 렌더 프레임 재생/픽셀 증거가 아니다.
